# 🚨 Smart AI Crime Hotspot Prediction & Emergency Response System

## 📌 Overview

The Smart AI Crime Hotspot Prediction & Emergency Response System is an AI-powered analytics platform developed for Jaipur, Rajasthan using Python, Machine Learning, and Data Science techniques.

The system analyzes crime patterns, predicts crime severity, identifies high-risk areas, generates emergency alerts, visualizes crime hotspots on interactive heatmaps, and provides AI-based safety recommendations.

This project aims to support smart-city policing, urban safety analysis, and intelligent crime monitoring.

---

# ✨ Features

## 🔥 Crime Hotspot Prediction
Predicts high-risk crime zones using Machine Learning algorithms.

## 🗺 Interactive Jaipur Heatmap
Visualizes dangerous and safe areas using interactive Folium maps.

## 📊 AI Crime Analytics Dashboard
Professional Streamlit dashboard with:
- Interactive graphs
- Crime trend analysis
- Crime distribution insights
- Hourly crime analysis

## 🚨 Emergency Alert Generation
Automatically detects dangerous zones and displays alerts.

## 👩 Women Safety Index
Calculates safety score for women based on crime risk.

## 👮 Police Patrol Recommendation
Suggests areas requiring increased police surveillance.

## 🤖 Future Crime Severity Prediction
Predicts:
- Low Crime Risk
- Medium Crime Risk
- High Crime Risk

using Random Forest Machine Learning algorithm.

# 🧠 Machine Learning Used

## Random Forest Classifier

The project uses the Random Forest algorithm for crime severity prediction because:
- high accuracy
- robust performance
- handles multiple features efficiently
- suitable for classification problems
